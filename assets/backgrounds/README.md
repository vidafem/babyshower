# Carpeta de Fondos (Backgrounds)

Coloca aquí tus imágenes o patrones de fondo:
- Fondos de acuarela, mármol, texturas de papel lino o degradados suaves.
- Formatos ideales: `.webp` o `.jpg` optimizados.

En `css/style.css` puedes cambiar la variable `--bg-texture` por la ruta a tu archivo:
```css
:root {
  --bg-texture: url('../assets/backgrounds/mi-fondo.jpg');
}
```
