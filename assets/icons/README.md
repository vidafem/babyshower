# Carpeta de Iconos (Icons)

Coloca aquí iconos en formato `.svg` o `.png` para:
- Código de vestimenta (smoking, vestido de gala, guayabera, etc.)
- Ubicación / Iglesia / Salón de eventos
- Calendario / Reloj
- Mesa de regalos / Tarjeta bancaria
- WhatsApp

La plantilla ya incluye elegantes iconos SVG vectoriales nativos para que no dependas de librerías pesadas como FontAwesome, garantizando carga instantánea.
