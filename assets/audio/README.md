# Carpeta de Música Ambiental (Audio)

Coloca aquí tu canción o melodía favorita para la invitación en formato `.mp3`.
- Nombre sugerido: `ambient.mp3`
- Para evitar tiempos de carga lentos en datos móviles, procura que el archivo pese menos de 2 MB (o un clip de 1 a 2 minutos en bucle suave).

La web incluye un botón de control de sonido (reproducir/pausar) discreto y elegante en la esquina de la pantalla.
